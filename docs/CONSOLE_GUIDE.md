# AWS Management Console Navigation & Evidence Guide

**AWS Region:** `ap-south-1` (Mumbai)  
This guide provides the exact step-by-step console navigation paths and matching AWS CLI commands for demonstrating every component of the ParkCloud architecture to faculty evaluators.

---

### 1. Consolidated View: AWS Resource Groups
- **Console Path:** AWS Console -> Search "Resource Groups & Tag Editor" -> Saved Resource Groups -> `ParkCloud-Demo`
- **What to point out:** All 9 cloud resources tagged with `Project=ParkCloud` appear in one single pane, proving unified IaC management.
- **Verification CLI:**
  ```bash
  aws resource-groups list-group-resources --group-name ParkCloud-Demo --region ap-south-1
  ```

---

### 2. Networking: Custom VPC, Subnets & Route Tables
- **Console Path:** VPC Console (`ap-south-1`) -> **Your VPCs** -> Select `parkcloud-vpc`
- **What to point out:**
  1. **CIDR Block:** `10.0.0.0/16`
  2. **Subnets:** 4 subnets across 2 AZs (2 public: `10.0.1.0/24`, `10.0.2.0/24`; 2 private DB: `10.0.10.0/24`, `10.0.20.0/24`).
  3. **Route Tables:** Public route table has a route to the Internet Gateway (`parkcloud-igw`); Private route table has NO internet route.
  4. **Endpoints:** Free `parkcloud-s3-gateway-endpoint` attached to route tables.
  5. **Cost Justification:** Zero NAT Gateway provisioned, saving ~₹2,738/month.
- **Verification CLI:**
  ```bash
  aws ec2 describe-vpcs --filters "Name=tag:Project,Values=ParkCloud" --region ap-south-1
  aws ec2 describe-subnets --filters "Name=tag:Project,Values=ParkCloud" --region ap-south-1 --query "Subnets[*].[SubnetId,CidrBlock,AvailabilityZone,Tags[?Key=='Name'].Value|[0]]"
  ```

---

### 3. Load Balancing: Application Load Balancer (ALB)
- **Console Path:** EC2 Console -> **Load Balancers** -> Select `parkcloud-alb`
- **What to point out:**
  1. **DNS Name:** The public HTTP entrypoint URL.
  2. **Subnet Mapping:** Spans two availability zones (`ap-south-1a`, `ap-south-1b`).
  3. **Target Groups:** Navigate to **Target Groups** -> Select `parkcloud-tg` -> Click **Targets** tab to show backend instance registered as **Healthy** with health checks hitting `/api/health`.
- **Verification CLI:**
  ```bash
  aws elbv2 describe-load-balancers --names parkcloud-alb --region ap-south-1
  aws elbv2 describe-target-health --target-group-arn <TARGET_GROUP_ARN> --region ap-south-1
  ```

---

### 4. Compute: EC2 Auto Scaling Group & Launch Template
- **Console Path:** EC2 Console -> **Auto Scaling Groups** -> Select `parkcloud-asg-*`
- **What to point out:**
  1. **Capacity:** Min: 1, Desired: 1, Max: 2.
  2. **Instance Management:** Show the active running backend instance.
  3. **Automatic Scaling Policy:** Click **Automatic scaling** tab to show Target Tracking policy maintaining average CPU at 60%.
  4. **Launch Template:** Click the template link to inspect the `user-data` bootstrap script and IAM instance profile.
- **Verification CLI:**
  ```bash
  aws autoscaling describe-auto-scaling-groups --auto-scaling-group-names <ASG_NAME> --region ap-south-1
  aws autoscaling describe-policies --auto-scaling-group-name <ASG_NAME> --region ap-south-1
  ```

---

### 5. Database: Amazon RDS for PostgreSQL
- **Console Path:** RDS Console (`ap-south-1`) -> **Databases** -> Select `parkcloud-postgres-db`
- **What to point out:**
  1. **Engine:** PostgreSQL 16.3 on `db.t4g.micro`.
  2. **Connectivity & Security:** Show **Publicly accessible: No**.
  3. **Subnets:** Multi-AZ DB subnet group in private subnets.
  4. **Security Group:** Inbound port 5432 restricted strictly to the app EC2 security group.
  5. **Encryption:** AWS KMS encryption enabled.
- **Verification CLI:**
  ```bash
  aws rds describe-db-instances --db-instance-identifier parkcloud-postgres-db --region ap-south-1 --query "DBInstances[0].[DBInstanceIdentifier,DBInstanceStatus,Engine,PubliclyAccessible,Endpoint.Address]"
  ```

---

### 6. Storage: Amazon S3 Private Bucket & Objects
- **Console Path:** S3 Console -> Buckets -> Select `parkcloud-storage-ap-south-1-*`
- **What to point out:**
  1. **Permissions:** "Block all public access" is **On**.
  2. **Encryption:** Server-side encryption with Amazon S3 managed keys (SSE-S3).
  3. **Bucket Policy:** Enforces `aws:SecureTransport` (HTTPS only).
  4. **Objects:** Show real PDF and CSV utilization reports generated by the backend under the `reports/` prefix.
- **Verification CLI:**
  ```bash
  aws s3 ls s3://<BUCKET_NAME>/reports/
  aws s3api get-public-access-block --bucket <BUCKET_NAME>
  ```

---

### 7. Security: IAM Role & SSM Parameter Store
- **Console Path 1 (IAM):** IAM Console -> **Roles** -> Select `ParkCloudEC2Role`
  - **What to point out:** Scoped least-privilege policies: `ParkCloudS3ScopedPolicy`, `ParkCloudSSMScopedPolicy`, `ParkCloudMonitoringScopedPolicy`. Zero wildcard AdministratorAccess.
- **Console Path 2 (SSM):** Systems Manager -> **Parameter Store** -> Filter by path `/${project_name}/demo/`
  - **What to point out:** Parameters for `/db/host`, `/db/user`, and encrypted `SecureString` types for `/db/password` and `/jwt/secret`. Zero plaintext credentials.
- **Verification CLI:**
  ```bash
  aws iam get-role --role-name ParkCloudEC2Role
  aws ssm get-parameters-by-path --path "/parkcloud/demo" --region ap-south-1
  ```

---

### 8. Monitoring: CloudWatch Dashboard, Logs & Alarms
- **Console Path 1 (Dashboard):** CloudWatch -> **Dashboards** -> Select `ParkCloud-Operational-Dashboard`
  - **What to point out:** 4 live widgets: EC2 ASG CPU Utilization, ALB Request Count & Latency, RDS Active Connections, and Custom Metric `LotOccupancyRate`.
- **Console Path 2 (Alarms):** CloudWatch -> **Alarms** -> Show:
  - `ParkCloud-HighCPU-Alarm` (> 70% for 5 mins)
  - `ParkCloud-UnhealthyTargets-Alarm` (UnHealthyHostCount >= 1)
- **Console Path 3 (Log Groups):** CloudWatch -> **Log groups** -> Select `/parkcloud/app-logs` (14-day retention).
- **Verification CLI:**
  ```bash
  aws cloudwatch describe-alarms --alarm-names "ParkCloud-HighCPU-Alarm" --region ap-south-1
  aws cloudwatch get-dashboard --dashboard-name ParkCloud-Operational-Dashboard --region ap-south-1
  ```

---

### 9. Notifications: Amazon SNS
- **Console Path:** SNS Console (`ap-south-1`) -> **Topics** -> Select `parkcloud-alerts-topic`
- **What to point out:** Email subscription attached to topic; status shows "Confirmed" once recipient validates the AWS confirmation link.
- **Verification CLI:**
  ```bash
  aws sns list-subscriptions-by-topic --topic-arn <SNS_TOPIC_ARN> --region ap-south-1
  ```

---

### 10. Cost Governance: AWS Budgets
- **Console Path:** AWS Billing & Cost Management Console -> **Budgets** (Global)
- **What to point out:**
  - Budget Name: `parkcloud-monthly-cost-budget`
  - Limit: $25.00 USD (~₹2,100 INR)
  - Thresholds: Alerts at 50% ($12.50), 80% ($20.00), and 100% forecasted ($25.00).
- **Verification CLI:**
  ```bash
  aws budgets describe-budgets --account-id <ACCOUNT_ID>
  ```
